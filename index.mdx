typescript-eslint is the industry-standard toolchain for linting TypeScript code with ESLint. It provides a custom parser, a rich plugin with over 100 TypeScript-specific rules, and ready-made shared configurations so you can enforce code quality and consistency across any TypeScript project.

## Why typescript-eslint?

ESLint's built-in rules only understand JavaScript. typescript-eslint bridges that gap by providing a parser that transforms TypeScript source code into an AST that ESLint can traverse, then adding rules that understand TypeScript-specific syntax and types.

<CardGroup cols={3}>
  <Card title="Type-aware rules" icon="magnifying-glass">

## Get started

<Steps>
  <Step title="Install packages">
    Install ESLint, TypeScript, and typescript-eslint.

    <CodeGroup>
    ```bash npm
    npm install --save-dev eslint typescript typescript-eslint
    ```
    ```bash yarn
    yarn add --dev eslint typescript typescript-eslint
    ```
    ```bash pnpm
    pnpm add --save-dev eslint typescript typescript-eslint
    ```
    </CodeGroup>
  </Step>
  <Step title="Create your config">
    Create `eslint.config.mjs` at the root of your project.

    ```js eslint.config.mjs
    // @ts-check
    import js from '@eslint/js';
    import { defineConfig } from 'eslint/config';
    import tseslint from 'typescript-eslint';

    export default defineConfig(
      js.configs.recommended,
      tseslint.configs.recommended,
    );
    ```
  </Step>
  <Step title="Run ESLint">
    Lint your TypeScript files.

    ```bash
    npx eslint .
    ```
  </Step>
  <Step title="Enable typed linting (optional)">
    For the most powerful rules, enable type-aware linting. See the [Typed Linting guide](/getting-started/typed-linting) for setup details.
  </Step>
</Steps>
